# Reported results

All files in this folder are **values reported in the paper** (tables, text, Fig. 5), transcribed for convenience.
They are summary statistics, not per-clip data, and cannot be used to retrain or re-evaluate the model.
Means and SDs are over five random seeds, in percent unless noted.
To recompute these numbers from per-clip outputs, use `scripts/evaluate.py` with files in the formats described in `data/README.md`.
